# tool-data-ready-ai

## وصف المشروع

مشروع بسيط لمعالجة وتجهيز البيانات لتكون جاهزة للاستخدام في مشاريع الذكاء الاصطناعي والتعلم الآلي.

يهدف المشروع إلى تنظيم البيانات الخام وتنفيذ عمليات تنظيف وتجهيز البيانات قبل استخدامها في النماذج.

## المتطلبات

* Git
* Python 3
* نظام تشغيل يدعم تشغيل Python وGit
* البيانات المطلوبة داخل مجلد `raw/`

## طريقة التشغيل

1. استنساخ المستودع:

```bash
git clone <repository-url>
```

2. الدخول إلى مجلد المشروع:

```bash
cd tool-data-ready-ai
```

3. وضع البيانات الخام داخل مجلد:

```text
raw/
```

4. تشغيل سكربت تنظيف البيانات:

```bash
python clean.py
```

5. يتم تنظيم البيانات الناتجة داخل مجلد:

```text
data/
```

## بنية المجلدات

```text
tool-data-ready-ai/
├── README.md
├── clean.py
├── clear
├── data/
├── mkdir/
├── gitignore
└── raw/
```

### الملفات والمجلدات

* `README.md` — توثيق المشروع وطريقة استخدامه.
* `clean.py` — سكربت Python لمعالجة وتنظيف البيانات.
* `raw/` — البيانات الخام قبل المعالجة.
* `data/` — البيانات بعد تجهيزها ومعالجتها.
* `clear` — ملف/أداة مساعدة ضمن المشروع.
* `mkdir/` — مجلد مرتبط بملفات المشروع.
* `gitignore` — ملف متعلق باستثناء الملفات التي لا نريد تتبعها في Git.
